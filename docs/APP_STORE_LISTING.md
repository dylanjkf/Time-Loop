# TIME LOOP — App Store Listing Copy

Store copy for **Time Loop**, a premium puzzle game (iOS + Android) about cooperating with your own past self via a ghost-replay mechanic. Word/character counts below are computed against Apple App Store field limits; see the **Google Play Notes** section at the end for where Android differs.

---

## App Name (App Store "App Name" field — 30 character limit)

**Time Loop: Ghost Puzzle**

*(23 / 30 characters)*

Rationale: keeps the real product name ("Time Loop") intact for brand recognition, and spends the remaining budget on two of the highest-value, highest-relevance search terms ("Ghost," "Puzzle") rather than a generic descriptor. Apple indexes every word in the App Name field for search, so this name alone covers "time," "loop," "ghost," and "puzzle" without needing them in the 100-character keyword field.

## Google Play Notes (where Play's limits differ from iOS)

Google Play's listing fields are **not** a 1:1 match with App Store Connect's, so the assets above need light adaptation, not a rewrite:

- **App title:** Play also caps the title at 30 characters (same as iOS), so **"Time Loop: Ghost Puzzle"** can be reused as-is.
- **Short description (Play-only field, 80-character limit):** Play has no separate "Subtitle" field — instead it has an 80-character **Short Description** that appears in search results and at the top of the store listing, and Google's algorithm *does* weight it for ranking (unlike iOS, where ranking runs off the dedicated Keywords field instead). Don't just reuse the 30-character Subtitle here; write a keyword-denser 80-character version instead:
  > Team up with your past self in this brain-teasing time-loop puzzle adventure. *(77 / 80 characters)*
- **No Promotional Text field:** Play has nothing equivalent to iOS's editable Promotional Text. Fold that hook into the opening lines of the Full Description instead (Play truncates the description preview in search results, so the first ~2–3 sentences function as Play's de facto promo text — lead with the same "you are never alone in the room" hook).
- **Full description (4,000-character limit):** identical limit to iOS, so the Description above can be pasted in unchanged. One difference in practice: Play's algorithm rewards natural keyword repetition in the body text (title/short description/full description keyword density drives Play Store search, since there's no dedicated keyword field — see `ASO_KEYWORDS.md`), so if Play impression share is underperforming after launch, the highest-leverage edit is working 2–3 more natural mentions of "puzzle game," "brain teaser," and "time travel" into the Play-specific description body — not shortening it.
- **What's New:** Play allows up to 500 characters for release notes (vs. Apple's ~4,000-character practical allowance); the 8-bullet list above comfortably exceeds 500 characters as written, so for Play, trim to the top 3–4 bullets (recommend keeping the "Welcome," World 1/2, and Daily Challenge bullets; cut the achievements/hints and cosmetic-themes bullets, which are the least essential for a first-run install decision).
- **Screenshots/feature graphic:** the 8 captions work unchanged on Play, but Play additionally requires a 1024×500 feature graphic with no mandated text — reuse screenshot 1's caption ("Meet your new teammate: you, five seconds ago.") as the feature graphic's tagline for consistency across both stores.
